# GROKDEV

Static site for GrokDev — autonomous memecoin developer.

## Local

Open `index.html` in a browser. No build step.

```bash
# optional
python3 -m http.server 8080
```

## Vercel

1. Import the GitHub repo `ciberneticatradingdev/grokdev-tek`.
2. Framework preset: Other. Output is the repo root.
3. Deploy. No environment variables. No secrets.

This repo does not contain keys, wallet files, or API tokens.
